Write a function called `findProduct` that when given 2 integers, `num1` and `num2`, returns the product of all numbers between the two given integers, beginning at `num1` and excluding `num2`.

**For example:**

```
> findProduct(2, 5)  // calculates product of 2 * 3 * 4 
```

```
24
```

```
> findProduct(1, 3)  // calculates product of 1 * 2
```

```
2
```

**Notes:**

If `num1` is greater than `num2`, you can return 0.
